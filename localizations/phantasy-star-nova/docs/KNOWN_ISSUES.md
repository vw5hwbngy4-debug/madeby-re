# Known issues

## Vita3K CAST rendering

On the tested Vita3K setup a CAST player character can show black/glitched body materials. Setting **Disable Surface Sync OFF** restored the clothing, while parts of the CAST body could remain black.

NPCs, environments, UI, dialogue boxes and English text continued to render correctly. For clean capture footage, use a non-CAST character if affected.

## Translation quality

The previously untranslated remainder was completed using machine translation / LLM assistance. The release is intentionally rough-complete: functional English can still contain literal or awkward phrasing.

## Full playthrough

A full start-to-finish human playthrough of every branch, quest and DLC path is not yet claimed. This is a runtime-QA/playthrough dimension and does not reduce the translation-corpus completion figure: the audited enabled runtime translation corpus is 100% complete at 24,850 / 24,850 records.
