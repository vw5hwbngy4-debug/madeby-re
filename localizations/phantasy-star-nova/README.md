# Phantasy Star Nova — MadeBy localization archive

Static production package for the Phantasy Star Nova Complete English Text Build v1.0.

Suggested production hostname: `https://madeby.re/localizations/phantasy-star-nova/`.

> Note: DNS/HTTP hostnames should use hyphens rather than underscores. If you created a different Wolken subdomain, update the canonical/OG URLs in `index.html` and `sitemap.xml` before deployment.

## Deploy

Upload the **contents of this directory** directly into the document root for the subdomain. Keep the directory structure intact.

No server-side code or database is required.
