# Hostinger deployment

Deploy the contents of this directory to the document root of `localizations.madeby.re/xenosaga-nederlands`.

Do not deploy this Dutch package to `localizations.madeby.re/xenosaga`; that hostname is reserved for the English project.

After upload, purge Hostinger/cache/CDN caches and hard-refresh the browser. The HTML references versioned 2026-09-05 CSS/JS filenames to avoid stale assets.
