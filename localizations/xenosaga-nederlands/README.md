# Xenosaga I+II DS — Nederlandse vertaling v1.0.17

Static deployment package for `https://madeby.re/localizations/xenosaga-nederlands/`.

Primary and only patch on this site: **Complete Dutch Translation v1.0.17 Final**.
The English project lives separately at `https://madeby.re/localizations/xenosaga/` and in `Xenosaga-I-II-DS-English`.

The browser patcher verifies the clean Japanese source SHA-256 locally, verifies the Dutch BPS, applies it in a Web Worker, verifies the generated ROM SHA-256, and only then enables the local download. The user's ROM is never uploaded.
