# Bury Your AI Ideas · o-vvv-o

A playful local-first experiment for preserving the overflow of ideas that can happen during LLM conversations.

Instead of letting a thought, link, note, or small memory disappear into chat history, **o-vvv-o** turns saving it into a tiny spatial ritual: bury it in a field, move on, and rediscover it later.

## GitHub Pages edition

This repository contains the static standalone edition of the original o-vvv-o project.

- Runs entirely in the browser.
- Buried local items and chest state use `localStorage`.
- No account is required.
- No PHP, MariaDB, or hosting backend is required.
- The visual field, digging, biomes, weather, sparkles, chest, and local retrieval mechanics remain part of the browser experience.

The former hosted version also experimented with accounts, friends, messages, shared burials, and server synchronization. Those server features are intentionally **not** part of this GitHub Pages edition.

## Why it exists

LLMs can generate ideas faster than a person can comfortably organize them. A conventional notes list preserves the text, but often loses the moment and the sense of discovery. o-vvv-o explored a different interface: make memory spatial and playful.

**LLM idea overflow → bury → wander → rediscover.**

## Storage

This static edition stores its personal state in the browser. Clearing site data/localStorage can therefore remove locally buried material. It is not a cloud backup service.

## Origin

`o-vvv-o` is the original project/world name. `bury-your-ai-ideas` is the descriptive repository name for this preserved static edition.
