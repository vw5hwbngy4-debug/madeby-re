MANUAL INSTALL
--------------
1. In Hostinger hPanel create subdomain: pso.jrpg.world
2. Give it a CUSTOM directory such as: pso-v05
   IMPORTANT: do NOT point it to the existing public_html/pso directory.
3. Open that new pso-v05 directory in File Manager.
4. Remove Hostinger's default.php if present.
5. Upload this ZIP and extract it DIRECTLY inside pso-v05.
6. Confirm index.html is directly inside pso-v05, not inside another nested folder.
7. Visit: https://pso.jrpg.world/smoke-check.html
8. You want 9/9 checks passed.
9. Then visit: https://pso.jrpg.world/
10. Test ordinary RICO first, then link your local Xbox PSO save.
