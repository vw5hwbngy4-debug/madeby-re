GLORIA UNION ENGLISH FAN TRANSLATION v0.25
============================================================

REQUIREMENTS

- Windows
- Python 3
- The exact supported original Gloria Union Android APK

The patcher checks the complete original APK before changing anything. It stops
with an error if the APK is the wrong release or is damaged.

HOW TO PATCH

1. Extract every file from the downloaded patch ZIP into one folder.
2. Double-click PATCH_WINDOWS.bat.
3. Drag your original Gloria Union APK into the window and press Enter.
4. Wait for both SHA-256 verification steps to finish.
5. The new file appears beside the original as:
   GloriaUnion-English-v0.25.apk

The original APK is never modified.
