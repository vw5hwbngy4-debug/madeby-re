EXACT CONSOLE / GAMECUBE-XBOX IMPLEMENTATION
1. Start sum at 5.
2. Iterate the name using JavaScript UTF-16 charCodeAt values. Add each character code.
3. Character-set transition handling from the packaged calculator:
   - Maintain a flag initially 0.
   - If code >= 0x0100 and code < 0xFF61, desired flag is 2.
   - Else if code <= 0xFF91, desired flag is 1.
   - When desired flag differs from the current flag, switch flag and add 45 once for that transition.
4. index = ((sum % 10) + 10) % 10.
5. Map index through the Section-ID order above.

IMPORTANT IMPLEMENTATION NOTE
For ordinary ASCII names, the first character enters flag state 1, so the first character contributes the calculator's 45-point transition bonus. Preserve this exact behavior. Do not simplify it to only “sum the letters + 5”.

REFERENCE PSEUDOCODE
function ricoConsoleSectionId(name):
    ids = [Viridia, Greenill, Skyly, Bluefull, Purplenum, Pinkal, Redria, Oran, Yellowboze, Whitill]
    sum = 5
    flag = 0
    for each UTF-16 code unit in name:
        sum += code
        desired = flag
        if code >= 0x0100 and code < 0xFF61:
            desired = 2
        else if code <= 0xFF91:
            desired = 1
        if desired != flag:
            flag = desired
            sum += 45
    index = ((sum mod 10) + 10) mod 10
    return ids[index]
