------------------

Q          -> L
W          -> R
Enter      -> START
Numpad Enter -> START

DESIGN RULE
-----------
The face-button row is spatial:
  Z   X   C
 SEL  B   A

This fixes the old desktop map where Z triggered A even though the GBA A button
is physically to the right of B. Shift/Space and literal A/B aliases are no
longer game controls, removing hidden/ambiguous desktop bindings.
