TARGET BUG
On iPhone, selecting a .sav from Files could return to a Save Vault that still showed SAVE 2 / SAVE 3 as EMPTY with no import status at all.

ROOT-CAUSE ASSERTION
PASS — active slot DOM is rebuilt by renderAll().
PASS — v0.1.13.3 used per-card <input type=file> nodes inside that rebuilt DOM.
PASS — import handling depended on a delegated modal change listener.
PASS — replacing the original input while the native iOS Files sheet is open can detach it from the modal, so its eventual change event cannot reach the delegated listener.

PATCH ASSERTIONS
PASS — active v0.1.13.4 contains no data-import transient file inputs.
PASS — one persistent #sv-import-file-global is appended outside the slot-card DOM.
PASS — IMPORT buttons store target slot state before opening the native picker.
PASS — persistent picker owns its own direct change listener.
PASS — selected File is captured independently of later Save Vault re-renders.
PASS — upload is round-trip checked through action=download with SHA-256 equality.
PASS — successful import additionally requires the slot to appear in refreshed action=list data.
PASS — exact failure reason remains visible in the slot card.
