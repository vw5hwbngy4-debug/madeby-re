CALL / RESET
Selectors start with CALL BY... / CHOOSE... / RANK BY..., no implicit criterion.
Numeric inputs start empty. Valid predicate required before flute CALL enables.
Each category is a facet; each IV stat is its own facet. HP TYPE and HP POWER
are separate facets. Same-facet CALL replaces in place, exact repeats deduplicate,
and different facets intersect. Chips remove individual predicates.
Zero matches never permit FOCUS. Nonzero responses highlight FOCUS.
FOCUS promotes identities, clears predicates/rank/tier and resets controls.
SCATTER additionally removes focus, showing the entire current party.
Live changes re-evaluate calls; focus remains identity-based through slot moves.

RANK
Vertical S/A/B/C/D/E rows, based on fixed metric thresholds, not party percentiles
or competitive tiers. Empty rows disabled. Select a nonempty row to answer with
that tier; this clears previous CALL chips. FOCUS promotes that tier.
Unknown/egg values are Unranked. Within rows, values descend with slot tie-break.
Thresholds below are S/A/B/C/D/E lower bounds (inclusive):
Individual IV: 31 / 26 / 21 / 16 / 11 / 0
HP power:     70 / 65 / 60 / 50 / 40 / 30
Total IV:    186 /156 /126 / 96 / 66 / 0
EV total:    510 /408 /306 /204 /102 / 0
Level:       100 / 80 / 60 / 40 / 20 / 1
Friendship:  255 /220 /180 /130 / 70 / 0
Ribbons:      32 / 24 / 16 /  8 /  1 / 0 (S = 32+)
Each row shows its numeric range. HP power input accepts integers 30–70;
individual IV 0–31, total IV 0–186 and level 1–100.
