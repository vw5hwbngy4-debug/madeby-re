MILESTONE
---------
v0.1.24 turns the immutable v0.1.23 exact PK3 source capsule into a deterministic sequential transfer path:

  exact Emerald PK3
      -> Pal Park-style PK4
      -> Poké Transfer-style PK5
      -> PK6 pre-bind contract

Native PK4 and PK5 stored entities are emitted encrypted and checksummed.
A PK6 binary is deliberately NOT emitted until a destination Gen6 save supplies the target trainer / 3DS context required by the supplied PKHeX conversion semantics.

PK3 -> PK4 IMPLEMENTED
----------------------
Grounded against PKHeX.Core PK3.ConvertToPK4 and supporting helpers:
- PID, OID/TID/SID and National species identity
- held-item Gen3 -> Gen4 mapping/filter
- experience, friendship, language, form/gender context
- EVs, contest stats, IV data
- moves, PP Ups, PP repair
- ability ID mapping from supplied PKHeX enum
- Pokérus / game / ball / OT gender
- Pal Park met location 0x0037 and transfer date/level
- Gen III ribbon expansion
- Gen III HM stripping and move compaction
- native PK4 checksum/encryption
- exact Pal Park nickname/OT glyph conversion
- exact language-specific Pal Park string buffer residue / trash-byte reuse
- exact Gen III default-name comparison for the PK4 IsNicknamed bit

PK4 -> PK5 IMPLEMENTED
----------------------
Grounded against PKHeX.Core PK4.ConvertToPK5 and supporting helpers:
- PID/OID/species preservation
- held-item transfer behavior
- explicit Gen V nature storage
- Poké Transfer met location 30001
- transfer date/level fields
- move/PP repair and transfer-HM cleanup
- actual PK4 nickname/OT buffer decoded and transferred to Gen V
- exact StringConverter345 TransferGlyphs45 invalid-character replacement behavior
- native PK5 checksum/encryption

PK5 -> PK6 SAFETY BOUNDARY
---------------------------
The compiler emits pk6.prebind.json rather than pretending a complete PK6 exists.
The pre-bind contract carries deterministic source-derived values including:
- encryption constant basis
- PID shiny-protection rule result
- TID/SID, species, EXP, language, nature, form
- met data, ball, Pokérus
- EV normalization to Gen VI per-stat max 252
- IVs and moves

It explicitly requires destination-save-derived fields such as:
- handling trainer name/gender
- 3DS console region / country / subregion context
- base friendship binding
- resolved Gen6 ability context

No HOME Tracker, HOME server history, target trainer, or 3DS geography is fabricated.

IMPORTANT CORRECTIONS MADE IN THE FINAL PARITY PASS
---------------------------------------------------
1. Default English Gen III names such as TREECKO are no longer falsely treated as nicknames merely because the UI displays Treecko.
2. PK4 IV32 bit31 now tracks exact Gen III default-name semantics.
3. The compiler rejects a decoded-PK3 species / UI specimen dex mismatch before conversion.
4. Pal Park nickname and OT residual bytes now follow the source-modeled buffer-reuse sequence rather than clean-string regeneration.
5. PK4 -> PK5 strings are transferred from the actual PK4 string buffers, preserving the transfer pipeline semantics.
