EMERALD v0.1.23 — HOME BRIDGE SOURCE CAPSULE QA
Date: 2026-09-09
Status: PASS

SCOPE
-----
This milestone establishes the immutable Gen III source boundary for the future
Pokémon HOME Bridge. It does NOT yet create a Pokémon HOME import or write to
Pokémon HOME. It captures and verifies the exact 80-byte stored Gen III Pokémon
record from the running Emerald session and can package it with provenance.

CURRENT BEHAVIOR
----------------
- Strategy Context exposes a HOME action.
- Owned party and PC-box Pokémon receive stable transfer references.
- Exact 80-byte PK3 source bytes are captured before higher-level decoding.
- Gen III encrypted payload checksum is revalidated locally before export.
- A source capsule can be generated locally containing:
    * exact .pk3 entity
    * manifest.json
    * README.txt
- SHA-256 and CRC32 provenance data are generated locally.
- Wild Pokémon cannot be exported before capture.
- Eggs cannot enter the migration path before hatching.
- No Pokémon HOME endpoint is contacted.
- No HOME Tracker is generated, guessed, or fabricated.
- No save data is modified by this P0 bridge.

PKHEX SOURCE AUDIT
------------------
The user-supplied PKHeX source was reviewed as a research/test oracle.
Relevant upstream conversion chain is sequential:
  PK3 -> PK4 -> PK5 -> PK6 -> PK7
The source also confirms generation-specific transfer mutations rather than a
raw-format cast, and contains legality settings around missing HOME Tracker
values. PKHeX is GPLv3; no PKHeX source code is vendored into this browser build.
