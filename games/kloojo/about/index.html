Skate the city. Share the city.

Kloojo is an original browser-native 3D social skating, graffiti and traversal game created by Raynor Eissens and developed through sustained collaboration with GPT/OpenAI models, direct playtesting and iterative repair.

The game grew from a single-player skate prototype into a shared 3D world with a recovered canonical runtime, mobile controls, traversal, graffiti discovery and real WebSocket social presence.

What exists now?

Social presence

Real WebSocket multiplayer, room/invite support, canonical remote Kloojo avatars, live names, live wardrobe changes, interpolation, reconnect handling, zone-aware presence and reconstructed remote movement/idle animation.

Skate + traversal

Skating, carving, powerslides, braking/reverse, jumping, tricks, halfpipes/vert, grinds, balance, wall rides, vaults, wallruns, wallclimb, ledges, swing and climb-hold traversal.

Graffiti discovery

23 hidden drive-by graffiti placements, traversal-dependent spots, a spray-summoned district portal and secret Skyline progression remain part of the Development Zone grammar.

Development method

Kloojo is built through sustained prompt-driven development with GPT/OpenAI models as the primary development partner, plus Codex runs for high-leverage engineering work, human playtesting on desktop/iPhone, bug reproduction and focused repair. Generated code is never treated as proof by itself: the player-visible build has to survive actual play.

Deployment status: the two-device multiplayer relay has been proven locally/LAN. The public production relay is not yet deployed to a permanent VPS, so uploading the static client to kloojo.com alone does not make worldwide multiplayer available. Server-authoritative shared coins/graffiti and automatic 2-player micro-instancing are also not part of this uploaded Codex build yet.

Design references

Kloojo discusses games such as Jet Set Radio Future, Mirror's Edge / Mirror's Edge Catalyst, Klonoa 2 and other movement games as comparative references for flow, traversal, discovery and playful vertical design. Kloojo is an independent original project and does not claim affiliation with those games or their publishers.
