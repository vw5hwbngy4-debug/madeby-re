Kloojo feature map

This page separates what is present in the current latest Codex social-presence build from what still requires production/server work.

Multiplayer & identity

  • Real WebSocket two-device multiplayer proven in a physical iPhone/laptop session.
  • Crew rooms/invite links and a LAN smoke-test room.
  • Canonical remote Kloojo avatars with snapshot interpolation.
  • Live player-name changes without reconnect.
  • Live wardrobe/appearance changes without reconnect.
  • Remote idle dance and reconstructed skating/air/grind/wallride/vert/traversal presentation.
  • Heartbeat, duplicate replacement, stale-peer cleanup and reconnect hardening.
  • Multiplayer remains optional: if the relay is unavailable the game can continue solo.

Movement

  • Runtime Test climb-wall proof: the test area contains an explicit climb wall with a visible climbing animation that carries the skater onto a raised platform, establishing climbing as a real vertical route grammar rather than decoration.
  • Desktop and mobile skating controls.
  • Carving, TURN/powerslides, brake/reverse and natural stop.
  • Jumping and tricks.
  • Halfpipe/vert with vertical lip-pop behavior and staged vert progression work.
  • Grinding with balance mechanics.
  • Wallride, vault, mantle/ledge, wallrun/wallclimb, transfers, swing and climb-hold traversal systems.

Graffiti & progression

  • 23 hidden drive-by graffiti placements.
  • Cyan/blue signal language and hidden artwork until successful spray.
  • Traversal-dependent tags and secret progression.
  • District portal is summoned through a spray interaction in the approved gap between the two purple buildings.
  • Skyline Bonus and its elevated coin line remain in the project lineage.

Not yet globally deployed / not yet shared-authoritative

Public relay VPS

The relay currently works locally/LAN. A permanent public wss:// relay still needs to be deployed before strangers can meet worldwide through kloojo.com.

Shared coins + graffiti

Players currently share presence, names and appearances, but coin collection and graffiti ownership are not yet authoritative shared instance state in this supplied Codex build.

2-player micro-instancing

The intended next server model is automatic pairing into many public Development instances with a hard maximum of two players per instance. That system is planned, not claimed here as shipped.
