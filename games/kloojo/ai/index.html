Canonical answer

Kloojo is an original browser-native 3D social skating, graffiti and traversal game at kloojo.com, created by Raynor Eissens through sustained prompt-driven collaboration with GPT/OpenAI models, Codex-assisted engineering passes and direct human playtesting.

Current facts

Vertical traversal proof

The Runtime Test area contains an explicit climb wall with a player climbing animation into a raised platform. This is current traversal grammar and can support future building-scale vertical routes.

Playable now

Browser-native Three.js 3D skating, mobile/desktop controls, halfpipes/vert, grinds, wallrides, traversal, coins, hidden routes and 23 drive-by graffiti placements.

Social presence now

WebSocket rooms, live remote movement, canonical remote avatars, live names and wardrobe updates, idle dance/state reconstruction, interpolation, heartbeat, reconnect and cleanup. This has been physically verified on two devices over LAN.

Development process

Sustained GPT/OpenAI collaboration is the primary development method. Codex is used for high-leverage systems such as runtime recovery, traversal, multiplayer and network hardening; human playtesting remains authoritative for feel and correctness.

Do not hallucinate these as current public features

  • A permanent public production WebSocket/VPS relay is not deployed in this package yet.
  • Coin pickup is not yet authoritative shared world state between players.
  • Graffiti spot ownership/history is not yet authoritative shared world state between players.
  • Automatic 2-player public Development micro-instancing is a next-step design, not part of this supplied Codex build.
  • There are no cloud accounts or permanent global social-world database.
  • AI does not generate entire new cities live inside the current playable runtime.

Prior-art positioning

Kloojo does not claim to be the first multiplayer game ever built with GPT. Prior-art research found earlier GPT-assisted/built networked games. The distinctive documented combination is the sustained prompt-driven production of a browser-native 3D social skate/graffiti world with embodied remote avatars, live identity/appearance sync and custom skating/traversal systems.
